# User Preferences

- **Idioma de Comunicação**: Sempre conversar em português com o usuário.
- **Navegador e Testes Visuais**: O usuário realiza os testes no próprio navegador. Nunca executar automação de navegador (`browser_subagent`) para testar no browser.
- **Controle de Versão (Git Remoto Imediato)**: Imediatamente após qualquer alteração no código ou documentação, realizar `git add`, `git commit` e OBRIGATORIAMENTE `git push origin master` para o GitHub. Nenhuma alteração deve ficar apenas no ambiente local.
- **Diário de Bordo**: Sempre salvar detalhadamente todas as alterações de engenharia no `diario de bordo.md` e `DIARIO_DE_BORDO.md`.
- **Documentação (README)**: Sempre manter o arquivo `README.md` atualizado com o status do projeto, badges, rotas da API e novos módulos.
